# @analytics-kit/next

Next.js / Fetch handlers that proxy Analytics Kit connectors without exposing API keys.

```bash
pnpm add @analytics-kit/next
```

The product site uses this in `apps/demo/app/api/analytics/route.ts`.

Part of [Analytics Kit](https://github.com/educlopez/analytics-kit). See the [root README](../../README.md) for setup, the connector contract, and publishing.
